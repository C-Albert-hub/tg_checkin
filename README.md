# tg_checkin
一个用于进行自动机器人签到的程序
# 项目结构
```
tg_checkin/
├── bots.json //添加需要的机器人
├── checkin.session  //生成的session文件
├── main.py 
├── tg_config.json // 配置api_hash和api_id
```
